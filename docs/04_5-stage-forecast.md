# Этап 4.5 — Прогноз и цель дня

Цель этапа: дать трейдеру инструмент планирования — установка цели на день и моделирование сделок от текущего депозита.

## Definition of Done

- [ ] Новая вкладка **"Прогноз"** (`/forecast`)
- [ ] Переключатель (тумблер) **"План / Онлайн"**
- [ ] Пользователь задаёт:
  - цель по депозиту
  - цель ROI на сделку (%)
  - дату, к которой нужно достичь цели
- [ ] Отображение предполагаемых сделок:
  - от текущего размера депозита
  - с настраиваемым % прибыли за сделку (slider 0.5% — 100%)
  - сколько сделок нужно для достижения цели с эффектом сложного процента
  - отображение каждой сделки до предполагаемой цели по депозиту (или на 10 строк вперёд)
- [ ] Цель дня отображается на дашборде (этап 2.6)
- [ ] Досрочное достижение цели показывает сводку с опережением

## 2. Расчёт предполагаемых сделок

### Входные параметры

- Текущий депозит (из портфеля / риск-настроек / ручной ввод)
- Желаемый % прибыли на сделку (slider: 0.5% — 100%)
- Цель по депозиту (например, $10,200)
- Дата достижения цели (например, 2026-06-01)
### Выходные данные
Текущий депозит: 
10,000
Цельдепозита:10,200 (+2%)

При % прибыли на сделку = 2%:

Одна сделка с прибылью 2% → $200

Достижение цели: 1 сделка

При % прибыли на сделку = 1%:

Сделка 1: 
10,000→10,000→10,100 (+$100)

Сделка 2: 
10,100→ 10,100→10,201 (+$101)

Достижение цели: 2 сделки (сложный процент)

## 1. Режимы работы

Страница имеет **переключатель (тумблер)**:

- **План** — симуляция, не влияет на реальные сделки
- **Онлайн** — фактические сделки + динамический пересчёт

## 2. Пересчёт после закрытия сделки (онлайн-режим)

1. Пользователь закрывает сделку
2. В таблицу добавляется новая строка с фактическими данными этой сделки
3. Все последующие **планируемые строки** пересчитываются:
   - От **реального депозита** (с учётом PnL и всех cashflow между сделками)
   - С сохранением пользовательского **% прибыли на сделку**
   - До достижения текущей цели **или** на 10 строк вперёд (если цель уже достигнута)

Пересчёт происходит **сразу после закрытия сделки** (при следующем рендере/запросе страницы).

## 3. Досрочное достижение цели

### Сводка (отображается вверху страницы)
Цель: 
10,200 к 2026−06−01
Достигнута:2026−05−25(на 7дней раньше)
Опережение:
+150 сверх цели

### Поведение после достижения цели

- Прогноз продолжает строиться на **10 строк вперёд** с текущим % прибыли на сделку
- Закрытые сделки остаются в таблице
- Пользователь может **скрыть закрытые сделки** (чекбокс/кнопка)
- При установке **новой цели** — прогноз пересчитывается под неё

Отображение на вкладке "Прогноз" — таблица

### Режим планирования

| Депо (до) | PNL за сделку | Депо итог | ROI за сделку | Плечо |
|-----------|---------------|-----------|---------------|-------|
| 10,000   | +$100 (1%)    | 10,100   | —             | —     |
| 10,100   | +$101 (1%)    | 10,201   | —             | —     |

- Количество строк = сколько сделок нужно для достижения цели
- "PNL за сделку" = депо до × (ROI на сделку / 100)
- ROI за сделку пустое (плановое значение уже в заголовке)

### Режим онлайн
Цель: 10,757
Плановый процент: 5%

| Депо (до) | PNL за сделку | Депо итог | ROI за сделку | Плечо |
|-----------|---------------|-----------|---------------|-------|
| 10,000   | +$95          | 10,095   | 0.95%         | 10×   |
| 10,095   | +$150         | 10,245   | 1.49%         | 5×    |
| 10,245   | +512,25(5% плановая) | 10,757        | —             | —     |

- Каждая строка = одна **закрытая** сделка (факт)
- ROI реальный (с учётом комиссий и фандинга)
- Плечо реальное
- После последней факт. сделки — планируемые строки `(планируется)`, которые **актуализируются** по текущему депозиту

## 4. Цветовая индикация таблицы

| Цвет | Условие |
|------|---------|
| 🟢 Зелёный | Строка закрытой сделки, PnL > 0 |
| 🔴 Красный | Строка закрытой сделки, PnL < 0 |
| 🟡 Золотой (яркий) | Строка, в которой **достигается цель по депозиту** |
| 🟡 Золотой (тусклый) | Строка, соответствующая **цели на день** (из дашборда) |

**Правила приоритета:**
- Если строка одновременно = цель по депозиту и цель дня → яркий золотой
- Планируемые строки (не закрытые) не имеют зелёного/красного фона

## 5. Кнопка "Скрыть закрытые сделки"

- По умолчанию: все строки видны
- При активации: показываются только планируемые строки (до цели или 10 строк)

## 8. Взаимодействие с другими страницами

- Из строки онлайн-режима → клик → переход на страницу **"Закрытые сделки"** с открытой карточкой этой сделки
- Цель дня / цель по депозиту отображается на дашборде (этап 2.6)
