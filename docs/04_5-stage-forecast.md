# Этап 4.5 — Прогноз и цель дня

**Статус:** выполнен (MVP).

Цель этапа: дать трейдеру инструмент планирования — цель по депозиту, производная **цель на день**, симуляция и онлайн-таблица шагов.

## Согласованные решения (продукт)

| Тема | Решение |
|------|---------|
| **Хранение** | Поля в `RiskSettings` (Prisma `risk_settings`), патч через `PATCH /api/settings/risk`. Отдельной таблицы `Forecast*` нет. |
| **Цели по депозиту** | **Независимо:** `forecastDepositTargetUsdt` (онлайн + дашборд), `forecastPlanDepositTargetUsdt` (только «План»). |
| **ROI на сделку** | **Независимо:** `forecastTradeRoiPercent` (онлайн + дашборд), `forecastPlanTradeRoiPercent` (план). |
| **Крайний срок** | Общий: `forecastDeadlineYmd` (`yyyy-MM-dd` в `displayTimeZone`). |
| **Старт онлайн-прогноза** | Опционально: `forecastStartedAtYmd`, `forecastStartEquityUsdt`, снимок `forecastStartTradesToGoal`. Пустая дата → все выходы журнала; указана дата → только выходы с неё; депозит на старт — база первой факт-строки (если не задан — equity на выходе). |
| **Цель дня** | **Производная**, отдельного поля нет. Формула в `forecast-engine`: `stepsPerDay = сделок_до_цели ÷ дней_до_дедлайна` (календарных, включая сегодня); PnL дня = компаунд `stepsPerDay` шагов с плановым ROI от текущего депозита режима. Пример: 45 сделок / 45 дней → PnL одной сделки. |
| **Скоуп журнала** | Как дашборд: `journalAllAccounts` + активный счёт; отдельного переключателя на `/forecast` нет. |
| **Дедлайн** | Конец календарного дня дедлайна в `displayTimeZone` (включительно). |
| **План: стартовый депозит** | Ручной ввод на странице (query `planDeposit`) или equity журнала / `accountBalance` из риска. |
| **Онлайн после убытка** | Плановый хвост от фактического депозита после выхода; % плана не меняется. |
| **Строка таблицы (онлайн)** | Одна строка = один **выход** (exit leg), не закрытый трейд целиком. |
| **Клик по факт-строке** | `/trades/closed?tradeId=…` с подсветкой карточки. |

## Режимы

### План

- Симуляция от стартового депозита плана с `forecastPlanTradeRoiPercent`.
- Сообщение о достижении: «Цель депозита достижима в симуляции»; при опережении к дедлайну (если при темпе 1 шаг/день уложились бы раньше) — «(опережение на N дн.)».

### Онлайн

- Фактические выходы (с опциональным фильтром от `forecastStartedAtYmd`) + плановый хвост с `forecastTradeRoiPercent`.
- Депо до — equity журнала на момент выхода (cashflow); при заданном старте и депозите — первая строка окна от `forecastStartEquityUsdt`.
- Цель дня: кумулятивный PnL **выходов текущего календарного дня** + плановый хвост; подсвечивается **последняя** строка серии, где сумма PnL ≥ цели дня.
- Прогресс: дата старта, дней прошло, сделок с начала, с плановым ROI к депозиту, опережение по сделкам vs график от старта.

## Цель на день (формула)

```
daysInclusive = календарных дней от сегодня до дедлайна включительно
tradesToReach = шагов компаунда от текущего депозита до цели
stepsPerDay = tradesToReach / daysInclusive
derivativeDayTargetUsdt = equity × ((1 + ROI/100)^stepsPerDay − 1)
```

Дробный `stepsPerDay` (например 41/46) — норма; «шагов до цели дня» в таблице — число **строк** до набора кумулятивного PnL ≥ цели дня, а не «сделок в календарный день».

## Досрочное достижение

- **Онлайн:** факт пересечения цели по строкам; `earlyByCalendarDays` до дедлайна; `surplusUsdt`.
- **План:** пересечение в симуляции; опережение по дням — разница дедлайна и числа сделок до цели (если 1 полный шаг в день быстрее графика).

## Цветовая индикация

| Цвет | Условие |
|------|---------|
| Зелёный | Факт, PnL > 0 |
| Красный | Факт, PnL < 0 |
| Золотой яркий | Достижение цели по депозиту |
| Золотой тусклый | Последний шаг серии «цель дня» |

Приоритет: цель депозита > цель дня > profit/loss.
