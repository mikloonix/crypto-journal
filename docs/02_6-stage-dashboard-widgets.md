# Этап 2.6 — Дашборд: PNL/ROI за день, цель, усреднение

Цель этапа: дать трейдеру мгновенную картину дневной эффективности и инструмент для безопасного усреднения.

## Definition of Done

- [ ] На дашборде открытых сделок отображаются:
  - PNL $ и ROI % за день (есть возможность выбрать за вчера)
  - Цель PNL/ROI за день (из вкладки "Прогноз")
  - PNL за день в фиатной валюте (USD/EUR/RUB по выбору, RUB по умолчанию)
- [ ] Блок **"Возможность усреднения"**:
  - анализ открытых позиций
  - безопасная зона входа (диапазон цен)
  - сколько % позиция уже сходила (max откат от входа)
  - динамика за последний час (падение/рост)
  - рекомендация: сколько маржи можно добавить

## 1. PNL/ROI за день

### Расчёт

- PNL за день = сумма PnL по **закрытым сегодня** сделкам
- ROI за день = (PNL за день / начальный депозит дня) × 100%

### Отображение

- Зелёный/красный цвет
- Сравнение с целью: "70% от цели"

## 2. Блок "Усреднение"

### Анализ позиции

Для каждой OPEN позиции:
Безопасный диапазон = средняя цена входа × (1 ± safeZonePercent)
safeZonePercent = (риск% / 2) / плечо (упрощённо)
- **Сходила на X%** = (max цена − avgEntry) / avgEntry (для LONG)
- **Динамика за час** = (текущая цена − цена час назад) / цена час назад
- **Можно добавить** = расчёт:
  - текущий риск позиции
  - оставшийся дневной лимит риска
  - безопасная маржа = (доступный риск / стоп-лосс расстояние)

### Источник цены для блока усреднения

- Переключатель: **авто (BingX / биржа)** и **вручную**
- При недоступности API — автоматически ручной режим с уведомлением
- Текущая цена для расчётов = выбранный источник
