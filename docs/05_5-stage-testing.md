# Этап 5.5 — Тестирование (минимальное, но достаточное)

Цель этапа: зафиксировать автоматические проверки расчётов и критичных сценариев до продакшена.

## Definition of Done

- [ ] Unit-тесты: модуль расчётов (`src/lib/calc.ts` или эквивалент) — PnL, средняя цена входа, при необходимости риск кросс-маржи (см. `04_1-stage-cross-margin-risk.md`)
- [ ] Unit-тесты: валидация `stopLoss` для `FUTURE`
- [ ] Интеграционные тесты: создание трейда → частичный выход → согласованность PnL с БД
- [ ] Интеграционные тесты: синхронизация BingX с моком API
- [ ] E2E (опционально, один сценарий): открыть сделку → закрыть → метрики на аналитике согласованы

## Инструменты (минимальный набор)

- Vitest + Testing Library для unit/компонентов
- При необходимости E2E: Playwright

## CI

- В pipeline добавить `npm run test:unit` и `npm run test:integration` (или единый `npm test` с разделением по проектам)

## Зависимости

- Логично начинать после стабилизации домена (этап 2) и расчётного модуля; расширять по мере появления эндпоинтов.
