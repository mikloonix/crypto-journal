# Этап 4 — Риск-менеджмент (правила + подсветка нарушений)

Цель этапа: добавить реальную пользу для фьючерсной торговли — расчет риска для открытых позиций и правила, которые предотвращают “слив”.

**Подэтап 4.1 (кросс-маржа, совокупный риск):** `04_1-stage-cross-margin-risk.md`.

## Definition of Done

- Пользователь настраивает:
  - депозит/баланс
  - риск на сделку (%)
  - риск на день (%)
  - максимальная просадка (%)
  - риск на все открытые позиции (%)
- Для каждой **открытой** сделки рассчитывается риск:
  - в $ и в %
- Сделки/операции подсвечиваются, если нарушают правила
- Есть API + UI для `RiskSettings`

## Модель данных

`RiskSettings` уже есть в Prisma — на этом этапе уточнить:

- `accountBalance` — актуальный баланс/депозит
- правила в % — фиксировать как проценты (0..100)

Опционально (если нужно точнее):

- хранить `dailyRiskUsed` по датам (таблица `DailyRisk`) или считать на лету по закрытым сделкам

## Расчеты риска (MVP)

Для фьючерсов риск зависит от stop-loss, поэтому нужно добавить:

- `stopLossPrice` (на уровне Entry или Trade)

Простой алгоритм:

- средняя цена входа по Entry
- риск = \(|avgEntry - stopLoss| * margin\) (или нотация позиции в USDT по марже — согласовать с `roadmap-full-v2.md`)
- риск% = risk / accountBalance * 100

Правила:

- риск% > riskPerTrade → warning
- сумма рисков по OPEN > maxOpenRisk → warning
- дневной риск (сумма рисков открытых + закрытые потери за день) > riskPerDay → warning
