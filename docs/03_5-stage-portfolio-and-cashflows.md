# Этап 3.5 — Портфель (ввод/вывод) и equity от депозитов

Цель этапа: вести учет **пополнений/выводов** по торговому аккаунту и строить “кривую капитала” относительно реального депозита/кэша, а не фиксированного `INITIAL_DEPOSIT`.

## Definition of Done

- Есть страница `/portfolio`
- Пользователь может вести **cashflow-операции**:
  - пополнение (deposit)
  - вывод (withdrawal)
  - (опционально) перевод между аккаунтами
- Для каждой операции сохраняются:
  - дата/время
  - сумма
  - валюта
  - курс/цена (если нужно приводить к USDT/USD)
  - комиссия (опционально)
  - заметка
- Equity curve на дашборде считается как:
  - стартовый баланс = сумма пополнений − сумма выводов (на дату начала)
  - далее кривая = стартовый баланс + кумулятивный PnL по сделкам + изменения cashflow
- Поддержка “аккаунтов” (минимально один):
  - `Account` (название, биржа, базовая валюта)
  - `Cashflow` привязан к `accountId`

## Модель данных (предложение)

- `Account`:
  - `id`, `userId`, `name`, `exchange?`, `baseCurrency` (например, USDT)
  - `createdAt`, `updatedAt`
- `Cashflow`:
  - `id`, `userId`, `accountId`
  - `type` (DEPOSIT/WITHDRAWAL)
  - `amount` (number)
  - `currency` (string)
  - `price`/`fxRate` (number, optional)
  - `fee` (number, optional)
  - `timestamp`
  - `note` (optional)

## UI/UX

- Таблица операций с фильтрами по периоду
- Быстрое добавление операции
- Итог по периоду: net inflow, текущий “расчетный” balance

## Риски

- Если считать equity без cashflow, график будет вводить в заблуждение при пополнениях/выводах.
