# Этап 3 — Аналитика и визуализация (метрики + графики)

Цель этапа: построить корректную аналитику по закрытым сделкам/трейдам и добавить графики, которые помогают улучшать торговлю.

## Definition of Done

- **Визуал и композиция экрана `/analytics` соответствуют референсным скриншотам в папке `docs/`** (карточки метрик, вкладки графиков, таблица истории, фильтры по символам и периоду). Отклонения только по согласованию (документировать в PR).
- Основные метрики считаются корректно на выбранном периоде:
  - PnL (суммарный), PnL %, Winrate, Avg win/lose, Profit factor, Risk/Reward
- Доступна аналитика по срезам:
  - монеты, стратегии, причины/сетапы, эмоции входа/выхода, время суток, дни/недели/месяцы
- Графики:
  - **Equity curve**
  - **PnL по времени**
  - **Статистика по стратегиям**
  - **Распределение прибыли/убытков**
- Период (дата от/до) влияет на все метрики и визуализации единообразно

## Источник данных и производительность

Рекомендуется считать агрегаты на сервере:

- API эндпоинт(ы) аналитики, принимающие фильтры
- Prisma запросы с выборками `entries/exits` только в нужном диапазоне

Оптимизация:

- пагинация для журнала
- отдельные lightweight endpoints для графиков/агрегатов

## Метрики (как минимум)

- **PnL**: сумма PnL по закрытым Trade в периоде (учесть fee/funding)
- **% доходности**: определить базу:
  - либо от `RiskSettings.accountBalance`
  - либо от “стартового баланса на период” (нужно хранить/восстанавливать)
- **Winrate**: count(pnl>0)/count(closed)
- **Avg win / Avg loss**
- **Risk/Reward**:
  - минимально: avgWin/abs(avgLoss)
  - лучше: использовать risk из риск-менеджмента (этап 4)

  - x: номер сделки или дата закрытия

  - bar chart: PnL по стратегиям

- Распределение:
  - histogram PnL (по бинам)

## Расширенные метрики (дополнительно к базовым)

> Источник: консолидация черновика из папки «Новые для анализа» (раньше ошибочно был заголовок «этап 7» — по смыслу всё относится к аналитике, этап 3).

- **Sharpe Ratio** — (средняя доходность − безрисковая ставка) / стандартное отклонение доходности
- **Maximum Drawdown** — максимальная просадка от пика equity
- **Expectancy** — (средний выигрыш × winrate) − (средний проигрыш × loss rate)
- **Recovery Factor** — чистая прибыль / максимальная просадка
- **Average Holding Time** — среднее время от открытия до закрытия трейда

### Max PnL / ROI по периодам

- За день / месяц / год / всё время
- Отдельно: максимум на **одну сделку**
- Отдельно: ROI **относительно открытой позиции** (не от депозита), где применимо

### Winrate — детализация

- Количество сделок всего
- Количество прибыльных / убыточных
- Winrate = прибыльные / всего × 100%
